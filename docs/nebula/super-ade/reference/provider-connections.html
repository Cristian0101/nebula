Provider Connections

High-fidelity reference for the E3 Provider Connections sheet. Every frame renders at its true pixel size in the proposed nebula-ion palette and scales to fit. Data is synthetic: no real account, login link, device code or pairing value appears anywhere. Where this page differs from the design documents, the documents win.

A

Overview, over the current project

Desktop 1440 × 900. The sheet (600px) opens from the sidebar summary, the toolbar CTA, the composer, banners, the model picker or the palette. The project route stays mounted behind the scrim. Cards keep a fixed order; the triage strip filters.

B

Provider detail

Pushed inside the sheet. Next action first, then account and sign-in, the seven E1 facts, reported billing and collapsed diagnostics. The detail's next action is the only solid violet control in the sheet.

C

Official sign-in flows

Each ceremony replaces the detail's status panel. Captions name the E2 state that drives each step. Login links show their host name only; device codes stay masked until revealed.

Codex · managed App Server · browser and device code

Cursor · configured official CLI · browser handoff

Claude · guided terminal, under the person's control

D

Recovery states

The thirteen required states, then seven supporting ones. Each shows its card label and the detail notice with one next action. Source tags name the E1 fact, E2 state or client condition that triggers it.

S

Interaction states

Controls, cards, facts, billing, triage, countdown, private code and shell entry points in each state an implementation must render.

R

Responsive

1280 laptop uses a 560px sheet. Under 768px the sheet is full screen with a sticky ceremony footer. At 1920px and wider the sheet becomes a 1000px two-pane view and never stretches further.

L

Dark and light

Both appearances come from the same theme roles. These two frames ignore the Frames toggle. nebula-ion is additive; E3 does not change the default theme.

M

Authentication state matrix

Every E2 lifecycle state and the client-only states, with the label, tone and primary action E3 renders.
